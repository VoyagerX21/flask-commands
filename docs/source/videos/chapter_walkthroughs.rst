Chapter Walkthroughs
====================

These are the “work through the chapter with me” videos. They map cleanly to
the documentation flow, so if you want the most guided experience, start here.

Install and First Run
---------------------

Get Flask-Commands installed, confirm the command works, and take the first
quick tour of the CLI.

Watch: https://youtu.be/nrFk9fAaiII

Starting a Project
------------------

Create a new Flask project scaffold and see what the default structure gives
you out of the box.

Watch: https://youtu.be/_bFQ9TUULWA

Create a Simple View
--------------------

Start with the smallest useful `make:view` example and see how template-first
scaffolding feels.

Watch: https://youtu.be/3uZEtSSAUzE

Nesting Views and Folder Structure
----------------------------------

Use dot notation to organize templates and keep the project tidy as the page
structure grows.

Watch: https://youtu.be/r6NmtDCquoE

Building the First Resource
---------------------------

Generate a real resource with route, controller, and model wiring so the app
starts feeling real.

Watch: https://youtu.be/e_rhD1al8A4

Adding a Second RESTful View
----------------------------

Extend the resource with a second RESTful page and see how the existing
structure keeps paying off.

Watch: https://youtu.be/b9WqM3Wi1J8

Nested Resources with make:view
-------------------------------

Wire nested routes and controller structure under a parent resource using
truthful dotted naming.

Watch: https://youtu.be/ar7tdbvqVSc

Three Levels Deep with Nested Resources
---------------------------------------

Push the relationship structure one level deeper and see how the package
handles the nesting for you.

Watch: https://youtu.be/9PpSvadbKIc

Welcome and Setup Videos
========================

This page collects the early orientation and setup material. It covers what the
project is, how to install it, how to start a project, and the small set of
core concepts readers should know before moving into the generator chapters.

Each video card keeps its own watched state in your browser, so you can close
the page and come back later without losing your place.
